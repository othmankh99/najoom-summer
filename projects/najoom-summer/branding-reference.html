Print Production Notes
For the Print Shop: All files should be delivered as PDF or AI (vector).
Add 3 mm bleed on all sides for cutting.
All colors in CMYK mode — not RGB.
Text must be outlined / converted to paths before sending.
Material suggestion: PVC foam board for signs, flex print for banners.
For the Graphic Designer: Use only Poppins (English) and Cairo (Arabic) — no other fonts.
Do not modify or stretch the star shape.
Maintain color values exactly — no approximations.
All text bilingual: Arabic first, English second.
Every file delivered separately, named by item number.
